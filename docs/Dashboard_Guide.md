# Dashboard Guide

This document provides a brief guide to the Ecco Stove CRM & Sales Dashboard.

## Dashboard Purpose

The dashboard provides an interactive view of:

- Lead generation
- Sales pipeline
- Opportunity value
- Marketing campaign performance
- Product performance
- Customer types
- Sales activities

## Dashboard Filters

The dashboard includes four interactive slicers:

- Product Name
- Campaign Name
- Country
- Sales Stage

Filters can be combined to analyse specific CRM segments.

## Key KPIs

| KPI | Description |
|---|---|
| Total Leads | Total number of leads |
| Qualified Leads | Number of qualified leads |
| Won Leads | Number of won leads |
| Conversion Rate | Won Leads divided by Total Leads |
| Total Pipeline Value | Total estimated pipeline value |

## Main Visualizations

### Leads by Product
Shows lead distribution across Ecco Stove products.

### Leads by Customer Type
Shows the distribution of leads across customer segments.

### Marketing Campaign Performance
Compares leads and won leads generated by marketing campaigns.

### Sales Pipeline by Stage
Shows the number of leads at each stage of the sales process.

### Opportunity Value by Stage
Compares opportunity amount with probability-weighted expected value.

### Sales Activities
Shows customer and sales interactions by activity type.

## Business Insights

The dashboard provides dynamic insights including:

- Top products
- Total pipeline value
- Expected pipeline value
- Top lead source
- Conversion rate

These insights update when dashboard filters are applied.

## Dashboard Workflow

```text
Raw Data
   ↓
Power Query
   ↓
CRM Tables
   ↓
Data Model
   ↓
PivotTables & DAX
   ↓
Interactive Dashboard
```
